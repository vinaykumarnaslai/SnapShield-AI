Project Title
SnapShield AI - On-Device Privacy Redaction for Snapdragon PCs

Brief Project Description (411/500 characters)
SnapShield AI is a privacy-first computer vision application for Snapdragon-powered HP Windows PCs. It detects faces and privacy-sensitive objects locally and produces a redacted image without sending the source to a cloud service. The prototype uses YOLOv5n in ONNX format, prefers ONNX Runtime's Qualcomm QNN Execution Provider/HTP NPU backend on Snapdragon, and keeps a CPU fallback for portable development.
